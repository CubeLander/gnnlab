## ST-GCN (AAAI 2018)

**Spatial Temporal Graph Convolutional Networks for Skeleton-Based Action Recognition**  
Sijie Yan, Yuanjun Xiong, Dahua Lin.

- Paper: https://arxiv.org/abs/1801.07455
- Pinned version: **arXiv:1801.07455v2**, revised 2018-01-25.
- PDF: https://arxiv.org/pdf/1801.07455v2
- DOI: https://doi.org/10.48550/arXiv.1801.07455

From the repository root, download the pinned paper for local reading:

```bash
mkdir -p papers
curl --fail --location --max-time 90 \
  --output papers/st-gcn-1801.07455v2.pdf \
  https://arxiv.org/pdf/1801.07455v2
```

The local PDF is intentionally ignored by Git. The arXiv page identifies the
[arXiv non-exclusive distribution license](https://arxiv.org/licenses/nonexclusive-distrib/1.0/license.html),
which grants distribution rights to arXiv rather than an explicit general
redistribution license. This public repository therefore tracks the citation
and retrieval instructions, not a mirrored PDF. The paper is third-party work
and is not covered by this repository's MIT license.
